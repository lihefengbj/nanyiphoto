## 2. 本地与生产的明确差异

- `NP_ENV`只允许 `local / test`；生产值立即拒绝启动。
- 本地开发令牌由开发者自行设置，不能信任 `X-WX-OPENID`或请求体 owner。
- 本地文件上传为受鉴权、限量的原始 PUT。COS 直传必须另行实现，不能把此路由放进云托管图片请求体。
- SQLite 事务通过 `BEGIN IMMEDIATE`串行化本地容量、幂等和状态写入；不能据此证明云数据库多实例实现已验收。
- 本地素材 URL 需每次附带 Bearer 令牌并重新检查任务状态，不是云端短时签名 URL。
- 审核接口关闭，内部 `moderate()`仅供已验证 Provider 接入与测试，不能直接公开成批准照片的接口。
- 当前后台维护只做本地补偿清理和单步 worker，没有正式平台回调、生产清理告警或商用兜底。
