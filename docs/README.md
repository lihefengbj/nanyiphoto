## 项目目标

1. 实现一个证件照生成器微信小程序
2. 支持各种热门证件照尺寸（一寸/二寸/护照/各类考试报名照等，JSON 规格引擎驱动）
3. 支持下载（保存相册，高清版可接支付/广告解锁）

## 核心流程

```
上传/拍摄 → AI 人像分割抠图 → 选择规格与底色 → Canvas 合成预览
→ （微调/美颜）→ 生成高清图 → 保存相册 / 排版照下载
```
