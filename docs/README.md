## 项目目标

1. 实现一个证件照生成器微信小程序
2. 首发 5-10 个已核验的规格，按用途、地区、年份与提交渠道区分
3. 审核通过后精确导出并保存；不保证报名通过，不默认允许禁止数字修改的用途
4. 在成品、安全与成本 PoC 通过后，逐步扩展小工具、历史、广告和增值功能

## 核心流程

```
选规格与底色 → 取图（高清源图留本地）→ 小图私有上传
→ 异步内容审核 + 人像抠图 → 双通过后取得素材
→ 编辑 / 合成 → 读回验证像素、格式、字节数 → 保存
→ 主动删除与补偿清理
```

## 本地校验

需要 Node.js 24 LTS，在仓库根目录执行：

```powershell
node scripts/validate-specs.mjs
node --test scripts/validate-specs.test.mjs
```

发布真实配置前执行 `node scripts/validate-specs.mjs --release path/to/specs.json`。当前示例目录全部禁用，此模式应失败；通过工具检查也不代替来源 / 用途的人工核验。
