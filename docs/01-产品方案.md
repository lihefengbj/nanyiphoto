# 01 产品方案

## 1. 背景与竞品分析

参考产品「证件照」小程序的核心链路：

**上传/拍摄照片 → 选规格 → 智能抠图换底色 → 预览微调 → 付费/免费下载高清图**

### 1.1 竞品截图分析（2026-10-14，基于实际界面截图）

**分享卡片**：主打"免费证件照、自动换底色、标准尺寸证件照全支持"，CTA 为「立即制作」。

**首页结构**（自上而下）：

1. 收藏引导横幅（"添加到我的小程序"，提升回访）
2. 大标题 + 卖点："证件照生成器 · 3秒快速生成"
3. 功能卡片区：
   - 主卡片「一寸证件照 25x35mm | 295x413px」（默认最热规格直达）
   - 工具卡片「证件照换底色」（已有证件照仅换背景色的轻量入口）
   - 工具卡片「证件照编辑」（修改文件 KB 大小与 DPI——考试报名照刚需）
4. 「热门证件照尺寸」列表（二寸 35x49mm | 413x579px、小一寸 22x32mm | 260x378px……，mm + px 双标注，列表式）
5. 底部 tabBar：首页 / 小工具 / 电子照 / 我的

**关键结论**：

- 变现以**免费 + 广告**为主（分享卡片明确打"免费"），付费下载不是第一优先级
- 「改 KB / 改 DPI」和「仅换底色」是高频刚需工具，必须纳入产品
- 规格需同时展示毫米与像素，方便用户对照报名系统要求
- 强调生成速度（"3秒"），抠图与合成链路必须足够轻量

### 1.2 竞品流程页分析（规格详情 + 上传引导页，2026-10-14 截图）

点击某个规格（如"一寸证件照"）后进入规格详情页，自上而下：

1. **规格说明面板**：规格名称 / 打印尺寸（25*35mm）/ 像素尺寸（295*413px）/ 文件大小要求（"无要求"，部分报名规格限制 20-200KB）/ 分辨率（300dpi）
2. **背景色预选**：7 色色板（深蓝 / 白 / 红 / 浅蓝 / 灰 / 渐变蓝 / 藏青），**在上传照片之前选定**，流程是"先定规格和底色，再传图"
3. **拍照建议**（3 条引导文案）：表情自然抬头挺胸平视前方 / 他人协助用后置摄像头拍摄更佳 / 穿深色衣服、白色或纯色背景墙前拍摄效果最佳
4. **双入口按钮**：「相册选择」（描边次要按钮）/「直接拍摄」（实心主按钮）

**对方案的影响**：

- 规格 JSON 需扩展字段：`printMM`（打印毫米尺寸）、`fileSize`（文件大小限制，如 "20-200KB" 或 "无要求"）、`dpi`
- 用户流程定型为：**选规格（详情页选底色）→ 上传/拍摄 → 抠图合成 → 预览微调 → 下载**
- 拍照引导文案是降低抠图失败率的关键，直接复用此结构

### 1.3 主要功能模块（综合推断）

- 热门规格入口（一寸、二寸、教师资格证、护照、签证、考试报名照等）
- AI 人像分割 + 换背景（白 / 蓝 / 红 / 渐变）
- 已有证件照换底色（轻量独立入口）
- 证件照编辑工具（压缩到指定 KB、修改 DPI）
- 美颜微调、正装换装（增值功能）
- 排版照（6 寸相纸排多张，用于冲印店打印）
- 变现：激励视频广告 / 流量主为主，高清或增值功能可付费

## 3. 技术架构

```
小程序端（原生 WXML/WXSS/JS，Canvas 2D）
   ├── 页面渲染 / 图片合成 / 保存相册
   └── wx.uploadFile 上传原图
后端服务（Python FastAPI 单服务，Docker 部署于微信云托管，常驻实例）
   ├── /api/matting    人像分割（自部署 RVM / MODNet 模型）
   ├── /api/specs      规格配置下发（便于热更新）
   ├── /api/order      订单与微信支付回调
   └── 对象存储 COS（临时图，24h 生命周期自动删除）
```

### 关键技术决策

- **人像分割**（已决策，2026-10-14）：**自部署 RVM 为主 + 商用 API 兜底**。主链路用 RVM（Robust Video Matting），单张 CPU 推理 < 1s，常驻实例固定成本约 30-80 元/月、调用不限次，与"免费+广告"模式匹配（商用 API 0.03-0.10 元/次，会贴穿广告收入线）；RVM 抠图质量差或服务故障时降级到腾讯云人体分割 API，兜底调用占比小、按次付费可忽略。人体/人像分割 ≠ 人脸识别，规避人脸识别类目资质门槛。
- **合成渲染**：小程序端 Canvas 2D 离屏画布完成底色 + 人像合成，无需服务端渲染，节省带宽。
- **下载**：`canvas.toTempFilePath`（2x 像素）→ `wx.saveImageToPhotosAlbum`，需 `scope.writePhotosAlbum` 授权，拒绝后引导去设置页开启。
- **支付**：微信支付需企业主体；个人主体版本以激励视频广告（流量主）变现。

## 4. 合规要点

1. 小程序类目：**工具 > 图片处理**。
2. 隐私政策：明确照片用途、传输加密、处理后 24 小时内自动删除；首次使用弹《个人信息保护指引》授权。
3. 不采集/存储人脸特征值，不做身份比对，规避人脸识别监管要求。
4. 内容安全：上传图片过一遍 `security.imgSecCheck` 内容安全检测。
