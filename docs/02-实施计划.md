# 02 实施计划

修订日期：2026-10-16

估算前提：一名熟悉小程序与 Python 的开发者、账号和测试设备可用。以下是工程工作量参考，不含账号注册、类目审核、资源申请及平台审核等待；PoC 后重新估算，不作为上线承诺。

## 1. 里程碑与放行条件

| 阶段 | 目标 | 工作量参考 | 放行条件 |
| --- | --- | --- | --- |
| M0 准备 | 账号资格、工程约束、规格契约、资源 / 存储选型 | 2-3 个工作日 | 账号与类目可行；规格、身份入口和持久化方案明确 |
| P0 PoC | 验证模型、素材合成、精确导出、上传 / 审核 / 删除 | 3-5 个工作日 | 形成可复现结果，定稿模型与素材契约、实例容量和合规待办 |
| M1 V1 MVP | 选规格 → 取图 → 审核 / 抠图 → 编辑 → 保存 | 7-10 个工作日 | 通过 06 验收矩阵；失败处理与安全闭环不可缺失 |
| M2 V1.1 | 小工具、本地历史、符合资格后的广告 | 5-8 个工作日 | 基于 V1 数据证明功能和变现收益 |
| M3 V2+ | 排版、美颜 / 换装、企业支付、冲印 | 分功能立项 | 分别完成用途、合规、供应商与成本评估后排期 |

若 PoC 未通过，不进入全量页面开发；调整模型、资源、素材方案或缩减范围后复测。四个 tab、20-50 种规格及增值功能均不作为 V1 放行条件。

## 2. 任务拆解

### M0 准备

- [ ] 在账号后台核实个人主体类目、隐私要求、广告资格与支付能力，保存检查日期和依据
- [ ] 申请云托管 / COS；核实当前请求、响应、上传大小和调用超时限制，不沿用未验证的旧限制数值
- [ ] 定稿受信身份入口、公网访问策略、限定对象上传凭证、私有桶权限和共享任务存储
- [x] 本地工程锁定 Node.js 24.18.1、Python 3.12.12 和已验证的后端依赖版本
- [ ] 建立云部署镜像并锁定基础镜像 digest；本机尚无 Docker 验证
- [x] 建立结构化规格示例、发布门禁校验脚本及其自动化测试
- [ ] 核验 5-10 个首发规格：用途 / 渠道、像素、格式、字节边界、底色、头部位置、来源与有效期
- [x] 初始化原生小程序 / FastAPI，本地接入规格、JS 结构 / 语法、Ruff 和单元测试，新增 CI 检查配置
- [ ] 完成 CI 远程实际执行、miniprogram-ci 预览上传和应用类型检查
- [x] 添加 `.gitignore`与不含真实凭证的 `.env.example`，隔离本地开发令牌并禁止生产启动
- [ ] 接入真实环境密钥管理、自动密钥扫描及生产日志脱敏检查

校验工具完成不代表规格已获官方核验；示例全部禁用且为草稿，不能直接发布。

### P0 PoC：先验证四条高风险链路

模型与画质：

- [ ] 用至少 50 张获授权图比较 RVM / PP-HumanSegV2 / MODNet，覆盖直发 / 卷发 / 碎发、眼镜、不同衣着、逆光、纯色及复杂背景
- [ ] 在目标实例测预热、P50/P95、峰值内存、并发 1 起的吞吐 / 排队，记录模型版本、哈希、分辨率、线程数与实例规格
- [ ] 对比“仅 alpha”“前景 + alpha”和边缘细化；使用白 / 红 / 蓝新背景检查污染、黑边、细节丢失
- [ ] 完成代码、权重、依赖及商用 API 许可检查；明确素材 alpha、方向和坐标契约

精确导出：

- [ ] Android / iOS 真机验证方向归一化、源图保留、Canvas 显示 / 渲染 / 导出尺寸分离
- [ ] 对固定像素与范围像素规格验证宽高、比例、真实格式及字节上下限；测试 JPEG 压缩无解分支
- [ ] 验证 DPI / 密度信息与保存相册后的文件；不能保留时撤销该链路的 DPI 保证或采用经验证的文件交付渠道

上传与删除：

- [ ] 验证上传凭证无法越权写对象、伪造 fileID / 身份无法取图、输出地址仅授权给所属用户
- [ ] 验证服务重启后任务可恢复；主动删除、过期补偿、失败重试和清理告警可观察

异步审核：

- [ ] 跑通实际接口提交与回调，不以提交成功代表审核通过
- [ ] 测试回调验签、重复 / 乱序 / 迟到回调、超时、取消，以及审核前不返回结果地址
- [ ] 记录实际审核延迟，明确其对首张可用预览的影响

PoC 产物：基准结果、真机成品文件、许可检查、身份 / 回调 / 删除测试证据、费用估算。仅有演示截图不算通过。

### M1 核心链路

后端：

- [ ] 实现 06 定义的上传登记、任务创建 / 查询 / 取消、审核回调、规格配置和健康检查接口
- [ ] 持久化 owner、幂等键、规格版本、审核 / 推理状态、租约、资产引用、过期和清理记录
- [ ] 模型预加载预热；有限推理队列与线程池；统一线程 / 进程配置，排队满时可预期拒绝
- [ ] 不可恢复错误不重试；可恢复错误有次数 / 时间上限；客户端重试不重复审核、推理或付费调用
- [ ] 经条件更新放行结果；未审核 / 非所属 / 已取消 / 过期任务不能获得素材
- [ ] 实现输入 / 审核副本主动删除、所有终态补偿清理、输出过期与清理失败告警
- [ ] 商用兜底可关闭，有超时、统一输出适配、预算、熔断及重试保护
- [ ] 规格 ETag / 缓存、版本固定、禁用 / 过期处理；禁用后不得创建新任务
- [ ] 指标覆盖各阶段耗时、P50/P95、队列、拒绝、审核、兜底、清理和费用，不记录图片或访问凭证

小程序：

- [ ] 首页、规格详情、取图、编辑、预览与保存；不展示不可用的增值入口
- [ ] 身份、对象上传、任务、规格模块独立封装，轮询与重试有上限
- [ ] 保留可取得的高分辨率源图，生成推理副本；识别不支持格式并提供明确引导，不把 `compressed`等同于保证原图或 HEIC 转换
- [ ] 显示审核 / 推理状态，支持取消；审核前无最终预览、保存 / 分享入口或素材 URL
- [ ] 前景 / alpha 合成、旧背景污染处理、拖动 / 缩放 / 重置与导出复用变换
- [ ] 精确设置 `wx.canvasToTempFilePath`导出参数，保存前重新读文件验证
- [ ] 处理弱网、上传失败、超时、压缩无解、规格失效、授权拒绝、内存不足和后台返回等场景
- [ ] 同意隐私后上传，用户取消 / 退出后清理不再需要的本地临时文件

验收：

- [ ] 按 [06 接口与验收规范](./06-接口与验收规范.md)逐项留存证据，至少覆盖 Android / iOS 及低内存设备
- [ ] 首发规格逐项验证成品；禁止数字编辑的用途不开放相关处理功能
- [ ] 在正常网络与弱网、单用户与目标并发下测整体 P50/P95，确认瓶颈和扩容阈值
- [ ] 用真实报价 / 账单计算成功单次成本，将失败、重试、数据库、存储 / 流量、审核和兜底纳入
- [ ] 核实隐私、照片用途、AI 标识 / 备案适用性和上架材料；问题关闭后再申请上线

### M2 体验与变现

- [ ] 已有证件照换底色、独立压缩 / DPI 工具，复用已验证导出管线
- [ ] 本地历史采用用户主动保存、预算与淘汰、一键删除，不默认增加云端相册
- [ ] 验证当期文件空间限制和保存失败行为，不将“200MB”视为所有设备恒定容量
- [ ] 满足后台资格后接广告，测完成率、用户流失、广告收入和生成成本
- [ ] 收藏、分享、客服 / 反馈；未审核素材不进入分享或历史记录
- [ ] 根据业务需要逐步启用四个 tab、扩展到 20-50 个已核验规格

### M3 独立增值项目

- [ ] 排版：精确相纸尺寸、DPI、边距和裁切线；实体打印验证
- [ ] 美颜 / 换装：用途许可、模型 / API 许可、效果、标识 / 备案、元数据保留与平台材料
- [ ] 企业支付：主体资格、订单状态、回调验签 / 幂等、退款和售后
- [ ] 冲印：供应商服务质量、收件信息最小化、第三方告知、结算和履约

## 3. 风险与放行原则

| 风险 | 对策 / 放行证据 |
| --- | --- |
| 低配实例达不到效果 / 延迟目标 | PoC 实测后改模型、实例、分辨率或产品目标，不承诺无限调用 / 固定 3 秒 |
| 发丝保留原背景 | 成品 A/B、前景恢复与边缘处理；不能只检验 alpha |
| 规格错误或规则变更 | 来源与渠道核验、发布校验、版本 / 过期 / 禁用、避免保证审核通过 |
| 上传或素材越权 | owner 检查、限定凭证、私有桶、受信身份和恶意输入测试 |
| 审核未完成即放行 | 持久化双状态、回调去重、条件放行，错误默认不通过 |
| 超时 / 重启造成重复费用或残留照片 | 幂等、租约、重试上限、预算和补偿清理 |
| 云资源成本高于广告收入 | 同周期全成本 / 成功次数，免费额度单列，付费兜底上限 |
| 类目、标识或用途不满足 | 账号后台与适用规则核验；未关闭问题不上线该功能 |
