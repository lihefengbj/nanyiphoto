## 2. 本批新增功能与边界

保留三个固定像素预设：295×413、600×600、600×800。
实验室新增 JPEG / PNG 和最小 / 最大整数 bytes，空值表示不限，边界包含端点。
输入端点为 1–10485760；来源中的 KB 或 KiB 需先人工核实，界面不自行换算。

无约束 JPEG 一次导出；有约束 JPEG 从 quality 0.92 向 0.55 最多尝试 8 次，
按读回尺寸、真实格式及字节数决定是否通过，不假定不同平台编码器字节数严格单调。
PNG 只导出一次；超限明确失败，不伪称 quality 能解决。

质量范围是待实测的 PoC 参数，不是最低成品画质保证。搜索失败只表示本次有界尝试没有合格候选；
不缩小固定像素、不添加填充，不开放保存未校验通过的文件。
DPI 尚未实现写入 / 读取保证，本批也未新增真实抠图、审核或上传。

为保证可管理删除，平台临时文件会移动到应用 `USER_DATA_PATH` 中随机命名的私有中间文件。
校验失败、替换、正常退出清理；删除失败保留归属并停止新导出，允许主动重试。
异常终止可能留下中间文件，下次导出或主动清理前只清扫保留命名空间，不读取照片内容，
不删除原照片 / 其他文件 / 仍在使用的导出文件。移动失败的未移动临时文件由微信管理。
不建立历史相册，不自动上传日志或图片；不能承诺强制退出时即时删除。

## 3. 新增能力真机复测矩阵

用户已确认本批整体复测通过。以下保留为证据补录和逐项覆盖清单，不将未提供的结果自动填写为通过。
至少分别记录 Android / iOS；有条件再覆盖低内存设备。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 基础回归 | 三个预设各用 JPEG、字节范围留空导出 | 一次编码，实际宽高等于目标，格式 jpeg，字节数正整数 |
| PNG | 三个预设选择 PNG，范围留空 | 实际 png，一次编码，尺寸不被 DPR 放大 |
| JPEG 有上限 | 先观察无约束大小，再设置可满足的较小上限 | 最多 8 次；成功时字节数在范围内，像素不变 |
| 包含端点 | 最小值 / 最大值设为实际文件字节数并使用相同输入 | 编码可复现时等于边界也通过；保留读回证据 |
| 搜索无解 | 最大字节数设为 1，分别试 JPEG / PNG | JPEG 最多 8 次、PNG 一次；明确失败，无保存入口 |
| 最小值无解 | 使用小图和明显高于实际大小的最小字节数 | 不填充凑大小，失败无保存入口 |
| 错误输入 | 最小值大于最大值、0、超范围值 | 不编码，明确输入错误 |
| 导出失效 | 成功后修改格式 / 范围 / 预设 / 构图或重置 | 旧证据和保存入口清空，须重新导出 |
| 重复点击 | 导出过程中连续点击导出 / 重置 / 切换设置 | busy 期间不可改变导出配置，不并发编码 |
| 正常退出 | 在导出 / 文件移动 / 读回期间退出页面 | 迟到结果不发布证据，可完成时清理私有文件 |
| 清理失败 | 用开发工具受控故障注入清理失败，再恢复并重试 | 保留失败归属，暂停新导出；重试成功后恢复 |
| 异常遗留 | 异常终止后重新进入并导出 | 新导出前清扫保留命名空间；其他文件不受影响 |
| 保存相册 | 校验通过后保存，再检查相册文件 | 保存成功提示不等于元数据保留；记录实际像素 / 格式 / 字节 / DPI |
| 权限与方向 | 拒绝隐私 / 相册，取消选图，带旋转信息照片 | 明确提示，未校验素材不可保存；当前未验证旋转方向仍拒绝 |

## 4. 采集方式与记录模板

开发者工具控制台在操作前开启诊断，操作后读取缓存：

```javascript
getApp().diagnostics.configure({ enabled: true, level: "INFO", maxEntries: 200 })
// 完成所测操作后：
JSON.stringify(getApp().diagnostics.snapshot(), null, 2)
// 保存安全日志后关闭；关闭会清空内存缓存：
getApp().diagnostics.configure({ enabled: false })
```

开启后只采集之后发生的事件，不能恢复开关关闭期间的历史操作。
真机采集方式以开发者工具支持的设备调试方式为准；没有原始运行日志时，不编造耗时或错误率。

每次记录：日期、平台 / 设备、系统 / 微信 / 基础库版本、测试代码版本、
预设、输入尺寸 / 格式 / 方向、目标格式与 bytes 范围、结果像素 / 格式 / bytes、
编码次数 / quality、保存后文件变化、错误码、是否清理、结论与证据位置。
照片需为获授权测试素材；不要把原照片、访问凭证或未经处理的完整平台错误写入日志或 Git。
