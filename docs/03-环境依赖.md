# 03 环境依赖

## 开发环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 或 macOS |
| 微信开发者工具 | 最新稳定版（Stable Build） |
| Node.js | >= 18 LTS |
| 小程序基础库 | >= 2.30.0（Canvas 2D 新接口） |
| Git | >= 2.40 |

## 小程序端

- 原生小程序框架（WXML / WXSS / JS，不使用第三方跨端框架，降低包体积）
- Canvas 2D（`type="2d"` 新接口，支持离屏画布）
- 网络层统一封装：屏蔽 `callContainer` / `wx.request + code2session` 差异，服务端形态迁移只改配置（模块职责：登录态、上传中转、接口调用）
- 上传链路：客户端压缩（最长边 512-1024px）→ **COS 直传**（不走 callContainer 请求体，官方限制请求 ≤100KiB）→ `wx.cloud.callContainer` 只传 fileID
- 权限申请：
  - `scope.writePhotosAlbum` 保存相册
  - 相机权限（拍摄）
  - 相册权限（选图）

## 后端服务

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Python | >= 3.10 | 推理服务运行时 |
| FastAPI + uvicorn | 最新稳定版 | HTTP 服务框架 |
| onnxruntime | >= 1.16 | RVM 模型 CPU 推理 |
| RVM (mobilenetv3) 模型 | rvm_mobilenetv3_fp32.onnx | 人像分割 |
| Pillow / opencv-python-headless | 最新 | 图像处理 |

部署方案（已决策，2026-10-14）：

1. **前期：微信云托管**（已确定）——FastAPI 单服务打 Docker 镜像部署，最小常驻实例数 1（满足"3秒生成"速度要求）。理由：免域名备案、`wx.cloud.callContainer` 免登录鉴权自动注入 openid、按量计费 MVP 成本近零（刊例价：0.5核1G ≈ 43 元/月、1核2G ≈ 86 元/月；首个环境送 3 个月免费额度）
2. **后期：自建服务器（腾讯云轻量 4C8G，约 100-300 元/月）**——量级上来或云托管成本不划算时平移。服务是标准 Docker 镜像，但调用方式需从 `callContainer` 切换为 `wx.request` + 域名备案 + code2session 登录态，小程序端网络层必须提前封装（见"小程序端"），迁移成本才能收敛到"只改配置"

注意：`wx.cloud.callContainer` 官方限制——请求 ≤100KiB、响应 ≤1MB、超时 ≤15s、请求中不建议包含图片；照片必须经对象存储 COS 中转（客户端直传，服务端按 fileID 拉取），抠图响应只回 alpha 蒙版（≤1MB）。

备注：业务接口不拆分独立 Node 服务，V1 由 FastAPI 单服务全部承载；业务复杂后再评估拆分。

备选商用 API（冷启动或兜底）：腾讯云人体分割、阿里云分割抠图。
