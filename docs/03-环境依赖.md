# 03 环境依赖

修订日期：2026-10-16

本文定义选型与锁定要求；目前未初始化应用工程，尚不存在应用依赖锁文件、模型文件或云环境。

## 1. 开发与验证环境

| 项目 | 基线 / 验证要求 |
| --- | --- |
| 操作系统 | 受支持的 Windows / macOS；发布与真机调试另核实开发者工具支持范围 |
| Node.js | 24 LTS，锁定具体补丁版本；不再以已停止维护的 Node.js 18 为基线 |
| 微信开发者工具 | 选择稳定版并记录完整构建号，不写浮动“最新”作为可复现环境 |
| 小程序基础库 | M0 按选用 API 确定最低支持版本；开发工具模拟器与真机均验证 |
| Python | 候选 3.12，PoC 确认模型 / ONNX 兼容后锁定具体补丁版本 |
| Git | 支持团队 CI 的稳定版本，CI 记录版本 |
| Docker | 与目标云托管 CPU 架构匹配；基础镜像锁定 tag / digest |
| 真机 | 至少 Android / iOS、低内存设备；记录系统、微信、基础库与文件交付渠道 |

依赖锁定在应用工程创建时完成；本文不编造未经安装、测试的包版本。规格校验工具仅使用 Node.js 内置模块，无需安装第三方包。

```powershell
node scripts/validate-specs.mjs
node --test scripts/validate-specs.test.mjs
# 发布前传入真实配置，检查至少一个启用且已核验的条目
node scripts/validate-specs.mjs --release path/to/specs.json
```

`--release`对当前草稿示例预期失败；通过结构校验不代表官方用途核验已完成。

## 2. 小程序端

- 原生 WXML / WXSS，JS 配合检查或原生 TS；不因前期规划引入跨端框架。
- Canvas 2D 与可用的离屏能力；设备能力探测与回退需实测。
- `wx.chooseMedia`取得照片后验证方向、格式和质量；单独生成推理副本，不以 `sizeType: compressed`保证高分辨率或格式转换。
- `wx.canvasToTempFilePath`明确 `destWidth / destHeight / fileType / quality`；输出重新读取校验，DPR 不改变规格目标像素。
- `wx.saveImageToPhotosAlbum`按当期隐私与授权要求调用；拒绝后引导设置，不循环弹窗。
- 独立封装身份、对象上传、任务调用、规格缓存。状态轮询、超时、取消和重试有上限。
- 缓存与临时文件采用应用自定预算 / 清理策略，并核实当期平台容量；默认不上传用户本地高清源图。

## 3. 后端与持久化

| 依赖 | 用途 | 锁定 / 检查要求 |
| --- | --- | --- |
| FastAPI / uvicorn | HTTP 与模型服务 | 精确版本、依赖锁、受信代理与 worker 配置 |
| onnxruntime | 候选模型 CPU 推理 | 与模型 opset / CPU 架构匹配，线程与内存基准 |
| RVM / PP-HumanSegV2 / MODNet | PoC 候选，不是预设上线模型 | 代码 / 权重来源、版本、哈希、许可与成品质量 |
| Pillow | 解码、方向、尺寸 / 格式检测、素材编码 | 精确版本；像素 / 文件大小限制，异常格式测试 |
| opencv-python-headless | 仅 PoC 证明后处理需要时加入 | 避免与其他库重复引入无必要处理能力 |
| COS / 上传凭证 SDK | 上传、读写、签名和删除 | 精确版本、最小权限、超时 / 重试与费用核验 |
| 共享任务数据库 / SDK | 幂等、owner、双状态、租约与清理记录 | M0 定稿云数据库，条件更新 / 唯一约束、多实例恢复实测 |

共享持久化不能以容器本地 SQLite 文件或内存字典替代上线实现。先保持单个业务 / 推理服务，队列与清理可借助任务存储和租约协调，不预先添加 Redis / MQ；容量不足后再评估。

## 4. 部署与第三方服务

| 服务 | 用途 | 当前状态 / 放行检查 |
| --- | --- | --- |
| 小程序账号 | 个人主体先验证图片处理及隐私要求 | 待申请 / 核实账号后台 |
| 微信云托管 | FastAPI Docker 部署 | 优先方案；实例规格、常驻 / 预热、请求限制、身份入口待实测 |
| 私有 COS | 输入、审核副本和输出素材 | 待开通；限定凭证、主动删除、生命周期兜底 |
| 云数据库 | 可恢复的共享任务与配置记录 | 待选型；纳入总成本 |
| `mediaCheckAsync` | 内容安全提交与异步结果 | 核实账号权限、当前接口版本、回调配置和结果放行 |
| 商用抠图 API | 可关闭的兜底 | 待核实资格、许可、结果格式、单价与预算 |
| 微信流量主 | 后续广告变现 | 当期门槛以账号后台为准，不预设固定 UV 数 |
| 微信支付 / 冲印供应商 | 企业增值项目 | 不纳入 V1；单独核实主体及服务能力 |

实例从至少一个常驻实例的方案开始测量，但其规格 / 扩容阈值由 PoC 决定。免费额度、旧刊例价和营销优惠不作为长期固定预算；数据库、流量、审核及兜底一起计费。

照片和素材走 COS，业务接口走小 JSON / 资产引用。M0 保存当期 callContainer / 网关 / COS 限制依据；异步任务创建返回后查询，不以固定同步等待时长承载推理和审核。

迁移自建服务器属于后续独立决策，需要域名 / 证书与适用备案、身份令牌、存储权限、回调、共享任务数据、清理与监控迁移测试，不称为“只改配置”。

## 5. 配置、凭证与安全边界

建议配置项（名称可在工程初始化时固定，示例不是已经部署的配置）：

- 环境 / 身份：`APP_ENV`、`WX_APPID`、受信入口策略与平台服务端凭证
- 存储 / 数据库：桶 / 地域、任务数据库连接、运行角色与清理角色
- 模型：版本 / 哈希、输入尺寸、线程 / worker 数、推理并发与有限队列
- 任务：上传大小 / 解码像素上限、截止时间、轮询上限、幂等保存时间
- 清理：未提交上传 TTL、任务 TTL、输入 / 输出保留时间、补偿扫描周期与失败告警
- 兜底：是否启用、API 凭证、调用超时 / 重试、每日金额上限、熔断阈值

安全要求：

1. 优先运行角色 / 短时凭证，不把长期 COS 写密钥发给客户端。
2. 后端凭证只存本地受控 `.env`或云端密钥配置，工程创建时加入忽略和密钥扫描；不同环境分离，支持轮换。
3. 关闭无鉴权公网入口或提供等效认证；不接受客户端伪造的用户身份 Header。
4. 上传对象绑定 owner / uploadId，文件解码和任务处理前校验权限与资源上限。
5. 短时素材地址不写日志或长期缓存；回调认证材料、照片、完整身份数据不进入诊断日志。
6. 删除结果、待清理数量和重试失败可审计；生命周期过期不等于按时删除成功。
