# 03 环境依赖

## 开发环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 或 macOS |
| 微信开发者工具 | 最新稳定版（Stable Build） |
| Node.js | >= 18 LTS |
| 小程序基础库 | >= 2.30.0（Canvas 2D 新接口） |
| Git | >= 2.40 |

## 小程序端

- 原生小程序框架（WXML / WXSS / JS，不使用第三方跨端框架，降低包体积）
- Canvas 2D（`type="2d"` 新接口，支持离屏画布）
- 权限申请：
  - `scope.writePhotosAlbum` 保存相册
  - 相机权限（拍摄）
  - 相册权限（选图）

## 后端服务

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Python | >= 3.10 | 推理服务运行时 |
| FastAPI + uvicorn | 最新稳定版 | HTTP 服务框架 |
| onnxruntime | >= 1.16 | RVM 模型 CPU 推理 |
| RVM (mobilenetv3) 模型 | rvm_mobilenetv3_fp32.onnx | 人像分割 |
| Pillow / opencv-python-headless | 最新 | 图像处理 |

部署方案（已决策，2026-10-14）：

1. **前期：微信云托管**（已确定）——FastAPI 单服务打 Docker 镜像部署，最小常驻实例数 1（满足"3秒生成"速度要求）。理由：免域名备案、`wx.cloud.callContainer` 免登录鉴权自动注入 openid、按量计费 MVP 成本近零
2. **后期：自建服务器（腾讯云轻量 4C8G，约 100-300 元/月）**——量级上来或云托管成本不划算时平移；服务是标准 Docker 镜像，迁移无改造成本

备注：业务接口不拆分独立 Node 服务，V1 由 FastAPI 单服务全部承载；业务复杂后再评估拆分。

备选商用 API（冷启动或兜底）：腾讯云人体分割、阿里云分割抠图。

## 主体类型（已决策，2026-10-14）

前期使用**个人主体**注册：无法开通微信支付，变现走流量主广告（免费模式，对齐竞品）；后续规模化、需要支付/冲印等增值功能时再迁移或新注册企业主体。

## 配置与密钥管理

- 后端环境变量：`COS_ACCESS_KEY_ID` / `COS_ACCESS_KEY` / `WX_APPID` / `WX_APP_CREDENTIAL` / `MCH_KEY`
- 密钥不入库，使用 `.env`（本地）+ 云托管环境变量（线上），`.env` 加入 `.gitignore`
