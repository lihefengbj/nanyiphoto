## 6. 接口、容量与清理

独立接口：

| 接口 | 作用 |
| --- | --- |
| `GET /api/lab/status` | 受鉴权就绪 / 固定错误码，不输出权重路径或令牌 |
| `POST /api/lab/jobs` | 有界二进制副本，强制授权确认头和幂等键 |
| `GET /api/lab/jobs/{job_id}` | 只返回 owner 的状态和有限模型 / 尺寸信息 |
| `GET /api/lab/jobs/{job_id}/cutout` | 只返回 owner 的 ready 透明 PNG；no-store |
| `DELETE /api/lab/jobs/{job_id}` | 取消并回收测试资产 |

一个工作线程串行调度，每次模型执行在自有独立 Python 解释器中；
子进程标准输出 / 错误接 `/dev/null`，不依赖父进程控制台，且不继承 `NP_*` 身份配置；默认每任务 120 秒，
超时 / 取消会终止自己的进程，不杀其他 Python。每张图 RVM 状态独立。
最多 4 个排队 / 处理 / 可用结果，记录总数最多 32，过期淘汰；满时返回 QUEUE_FULL。
成功前景的 RGB / alpha 先通过现有契约检查，再合成专供实验室的透明 PNG，
并未修改正式前景 RGBA 的 A=255 契约。

模型输入存储于私有 job 目录；子进程状态文件限 8192 bytes，
成功删除输入 / 状态文件，只保留透明图；失败先停止子进程、清理文件，再发布 failed 状态。
结果最长保留 600 秒，取消 / 正常服务退出主动回收。
本批 job 队列仅驻留本机进程，不是共享 / 持久化生产队列；强制退出可能留下私有目录，需人工清理，
不能把异常重启当作已保证恢复 / 删除。模型许可与身份、正式审核、COS / 云数据库仍未接入。
客户端请求 / 上传 / 下载超时 30 秒，轮询有 240 秒及 240 次上限，取消或退出立即停止后续轮询。
上传响应丢失时可能不知道 jobId，服务器 TTL 兜底；不无条件重试、重复推理或无限保留。
不删除源照片或其他文件；成功导出 / 切图 / 失败 / 退出清理只限保留命名空间的自有文件。
